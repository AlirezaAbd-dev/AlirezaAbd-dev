## 👨‍💻 About Me

I am a **Full-Stack & Systems Engineer** with a strong focus on **Systems Architecture**, **Applied AI Applications**, and **High-Efficiency Software Engineering**. I design and build mission-critical products that seamlessly bridge robust backend infrastructure, responsive client architectures, and cutting-edge artificial intelligence.

My engineering philosophy combines the speed and memory-safety of **Rust**, the industrial enterprise strength of **C# / .NET**, and the agility of modern **TypeScript / Next.js**, coupled with **Generative AI & LLM integration** to create software that is fast, resilient, and intelligent.

- 🤖 **Applied AI & LLM Systems**: Architecting production AI pipelines — combining LLM semantic comprehension (Gemini Pro, OpenAI) with deterministic finite state machines, stage-scoped prompt engineering, and Vision OCR verification.
- ⚡ **Extreme Performance Engineering**: Creator of [NEXA Mission Control](https://github.com/AlirezaAbd-dev/NEXA-Mission-Control), a self-hosted project management platform engineered in Rust & React that ships in a 42MB Docker image and consumes only ~30MB of RAM.
- 🌐 **Modern Full-Stack Mastery**: Building enterprise web applications using Feature-Driven Architecture, TanStack React Query, Zustand, Next.js App Router, and cross-platform touch-first PWAs.
- 🏗️ **Distributed Systems & DevOps**: Implementing Clean Architecture, Domain-Driven Design (DDD), Outbox patterns, and zero-downtime CI/CD deployment pipelines on Linux VPS servers.
- 💬 **Ask me about**: `AI Architecture & LLM Orchestration`, `Rust (Axum)`, `C# / .NET Core`, `NestJS / TypeScript`, and `Docker Optimization`.

## 🧠 AI Engineering & Intelligent Systems

I build real-world AI applications that go far beyond basic API wrappers, designing resilient architectures where non-deterministic AI models operate reliably within strict business domains:

```
┌────────────────────────────────────────────────────────────────────────────────────────┐
│                              PRODUCTION AI ARCHITECTURE                               │
│                                                                                        │
│  [ Multichannel Inbound ] ──> Rust Webhook Edge (Low-latency parser & deduplication)  │
│                                           │                                            │
│  [ Semantic Interpretation ] ──> Stage-Scoped Prompt Builder (Turn-aware context)     │
│                                           │                                            │
│  [ Hybrid State Machine ]  ──> Deterministic Decision Reducer (Guaranteed business rules)│
│                                           │                                            │
│  [ Multimodal Vision OCR ] ──> Bank slip & receipt verification with Vision AI        │
│                                           │                                            │
│  [ Reliable Outbox Delivery ] ──> Transactional Outbox Pattern for guaranteed dispatch │
└────────────────────────────────────────────────────────────────────────────────────────┘
```

### Key AI Competencies & Capabilities:
* **Hybrid AI + Deterministic State Reducers**: Designed architectures (such as the *NEXA AI Sales Assistant*) pairing probabilistic LLMs with deterministic finite state machines (`SalesDecisionReducer`), guaranteeing zero hallucinations in transactions, inventory, and order checkouts.
* **Stage-Scoped Dynamic Prompting**: Engineering turn-by-turn prompt orchestration (`SalesStagePromptBuilder`) that generates targeted, lean prompts based on current customer lifecycle stages rather than unmanageable monolithic prompts.
* **Multimodal AI & Vision Document Processing**: Implemented automated receipt, invoice, and payment slip verification pipelines using Vision LLMs and Base64 OCR across messaging networks.
* **Omnichannel AI Agent Adapters**: Integrated conversational AI agents across multiple social channels (Instagram, Telegram, Bale, Rubika) backed by transactional Outbox patterns for guaranteed delivery.
* **Heuristic AI & Search Algorithms**: Built intelligent graph-search and labyrinth pathfinding engines in C# / .NET using A*, Dijkstra, and state-space exploration algorithms.
